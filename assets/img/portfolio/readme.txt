Example: pd-1-img-0.jpg 

syntax:
pd-<project serial no>-img-<image serial no>.<file extension>

image serial 0 : thumbnail image
image serial >1 : project page slider image

file extension:
*.jpg : JPG file for thumbnail or slider image (location: assets/img/portfolio/)
*.gif : GIF file for slideshow in project page (location: assets/gifs/)
